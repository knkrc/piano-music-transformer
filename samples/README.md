# Samples

Generated by the LSTM baseline after 12,000 steps (validation perplexity 59.5),
with temperature 1.0 and top-k 32.

| File | How it was made |
|---|---|
| `lstm_unprompted.*` | Started from nothing but the begin-of-sequence token |
| `lstm_continuation.*` | Given four bars of a real MAESTRO performance and asked to carry on |

The MP3s are rendered with FluidSynth and the MIT-licensed MuseScore_General
soundfont, peak-normalised by a constant gain so the dynamics survive intact.

These are not cherry-picked from many runs — they are the second and first sample
of their respective batches, kept for being long enough to judge. Nine of twenty
unprompted samples end early, which the README explains.
